### Project Overview

The project is a simple web application that allows users to search location wise current weather and forecast. The application uses the OpenWeatherMap API to fetch the weather data.
<br><br>
The application will have the following features: 
<br>

● Allow users to search for weather forecasts by city name.
<br>
● Allow users to search weather forecasts for current location.
<br>
● Add user interaction features such as buttons and input elds for
selecting locations and viewing different weather data.
<br>
● Implement dropdown menu for recently searched cities.Clicking on any city in dropdown menu should update the weather data.
<br>
● Implement functionality to display extended weather forecasts for multiple
days
